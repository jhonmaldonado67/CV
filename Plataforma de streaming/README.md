# Plataforma de Streaming

Este proyecto es una plataforma de streaming full-stack desarrollada para gestionar y consumir contenido multimedia (series, películas, música y mangas).

## Características
- **Desarrollo Full-Stack:** Frontend y Backend integrados para una experiencia fluida.
- **Gestión de Contenido:** Visualización y reproducción de distintos tipos de medios.
- **Interfaz Moderna:** Diseño interactivo y amigable para el usuario.
